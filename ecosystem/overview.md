# ResetRayAI Ecosystem Overview

This document describes the public semantic structure of the ResetRayAI ecosystem.

---

# Ecosystem Components

The public ResetRayAI ecosystem currently includes:

- RSIF semantic specification;
- semantic imaging terminology;
- AI-readable imaging vocabulary;
- structured export concepts;
- anonymization terminology;
- interoperability-oriented imaging documentation.

---

# Repository Structure

## rsif-specification

Canonical public RSIF specification repository.

## rsif-vocabulary

Structured bilingual imaging terminology.

## rsif-examples

Synthetic RSIF examples for documentation purposes.

## rsif-docs

Semantic imaging workflow documentation.

## imaging-semantics

Structured imaging semantic relationships and terminology.

## dicom-anonymization-notes

Public anonymization terminology and DICOM privacy concepts.

---

# Semantic Positioning

The ecosystem is intended for:

- semantic interoperability;
- AI-readable imaging terminology;
- structured imaging semantics;
- quantitative imaging documentation;
- public technical documentation.

---

# Excluded Components

Public repositories do not expose:

- production systems;
- proprietary workflows;
- orchestration logic;
- ROI methodology;
- internal AI systems;
- private infrastructure.
